# Champions Companion: UI mockup (exported 2026-10-22)

| Folder / file | Format | Use it to |
|---|---|---|
| `champions-companion-mockup.pdf` | PDF, one page per screen plus a cover with the design decisions | Read, print, hand out. |
| `html/` | Standalone HTML + CSS, images embedded | **Edit.** Open `html/index.html` in a browser; edit any screen in VS Code (or any editor) and reload. Every colour, size and text is plain inline CSS. Links between screens work. |
| `png/` | PNG, full screen at 1x | Paste into slides, Word, Moodle. |
| `source/` | The original canvas files (`.dc.html` + `canvas.json`) | Keep for Claude: they are the editable source of the online canvas. They need the canvas runtime, so they don't open on their own. |

The online canvas stays the master copy and is still editable: https://claude.ai/artifact/33J4qu7y7wnVebn2n5U42r

In this export the background behind the pages is a blurred, darkened copy of `nebula_background.jpg`, approximating the canvas. The splash progress bar is frozen (it is animated on the canvas).
